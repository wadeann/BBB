## 四、策略稳定性验证（最重要的一章）

### 4.1 什么是 Walk-Forward OOS 验证？

简单说就是：**用历史数据训练策略 → 用未来数据验证 → 循环前进**

```
第1轮: 训练 [2024-10 ~ 2025-09] → 验证 [2025-10 ~ 2025-12] ✓
第2轮: 训练 [2025-01 ~ 2025-12] → 验证 [2026-01 ~ 2026-03] ✓
第3轮: 训练 [2025-04 ~ 2026-03] → 验证 [2026-04 ~ 2026-06] ✓
第4轮: 训练 [2025-07 ~ 2026-06] → 验证 [2026-07 ~ 2026-09] ✓
```

如果策略在4轮验证中**全部表现稳定**，说明它不是"数据挖掘的巧合"，而是有真实的预测能力。
