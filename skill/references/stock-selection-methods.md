# Skill: 选股方法体系

## Summary

从集合竞价选股、单阳不破形态选股、量能选股、基本面驱动选股等实战方法中提取的完整选股体系，涵盖早盘抓强势股、形态选股、量价分析、基本面筛选等多种策略，适用于不同市场环境下的个股筛选。

## Content

### 一、集合竞价选股法（早盘抓强势股）

#### 1.1 集合竞价三段时间规则

早盘集合竞价的15分钟划分为三个时间段：

| 时间段 | 操作规则 | 特点 |
|--------|----------|------|
| **9:15 - 9:20** | 可挂单、可撤单 | 虚拟集合竞价，存在假象，主力可制造虚假委托 |
| **9:20 - 9:25** | 可挂单、不可撤单 | 真实集合竞价，委托真实有效，反映真实意图 |
| **9:25 - 9:30** | 不可挂单、不可撤单 | 选股时间，集合竞价已结束，选出强势牛股的关键5分钟（股民可下单暂存券商系统） |

#### 1.2 选股四步骤

**第一步：打开涨幅排行**
- 在通达信软件中键入 `60`，打开沪深A涨幅排行榜

**第二步：总量从高到低排列**
- 点击"总量"，把成交量从高往低排列
- 原理：无量无人气，有量有行情。成交量起来说明有资金关注

**第三步：筛选涨幅区间**
- 在总量排行前30只股票中，选择涨幅在 **1% - 4%** 之间的个股
- 涨停的个股都是从这个涨幅推上去的
- 尽量选择换手率和量比都较高的标的（9:25之后开始挑选）

**第四步：形态筛选**
- 挑选形态结构上 **突破平台压力** 的个股
- 或 **均线多头排列**、容易拉升的形态
- 属于当前题材风口的人气股最佳

> **注意**：切忌追高——如果直线拉上去则不要去追，等待调整下来的机会，否则极易买在较高价位。

#### 1.3 黑马选股法（早盘涨停板战法）

**核心条件：**
- **量比 > 5**，越大越好
- **底部启动形态**，离近期低点很近，前期跌幅 > 50%
- **股价 < 50元**，涨幅 > 3%
- **流通盘 < 1亿**，流通市值 < 20亿
- 最佳买点：股价处于 **3% - 4%** 之间拉升状态中

**选股步骤：**
1. 打开沪深A涨幅排行
2. 点击"量比"排行
3. 在量比排行中选择排名靠前20只，量比大于5的股票

**筛选原则：**
- 剔除涨幅 **> 7%** 的股票（上涨空间有限）
- 剔除涨幅 **< 3%** 的股票（强势格局未打开）
- 剔除 **ST、\*ST** 个股（基本面亏损、涨幅受限）

**量比含义：**
- 量比 = 今天开市后每分钟平均成交量 ÷ 前五天开市后每分钟平均成交量之比
- 量比在 **10倍 - 20倍** 左右为具备资金关注潜力股，冲击涨停能力强

#### 1.4 交易原则

- **价格优先原则**：价格较高的买进申报优先于较低的买进申报
- **时间优先原则**：相同价格申报时，最早报出该价格的一方优先成交
- 强势股要"挂涨停板的价格"买入，以最高价格获得优先成交权

#### 1.5 注意事项

- 选股及判断一定在早盘开盘前、集合竞价时间完成
- 把握价格优先和时间优先原则
- 新兴产业（科技、医药等）胜率更大
- 切忌追高，等待调整机会
- 利润在手中，去留靠自己

### 二、单阳不破选股法

#### 2.1 定义

**单阳不破**：出现一根大阳线之后，后面几根K线盘整都没有跌破这根K线的最低价。这种形态的出现往往就是一个买入信号。

> **注意**：单阳不破并非一定指一根大阳线，也可以是 **两三根连续的小阳线**，上涨幅度超过 **7%** 即可。

#### 2.2 三种形态

| 形态 | 特征 | 操作 |
|------|------|------|
| **最强形态** | 大阳之后K线震荡上行，盘整期间创出大阳新高 | **最佳买点**，后续上涨动力强势 |
| **较强形态** | 大阳之后K线以震荡为主，没有创出大阳线新高 | 以 **大阳线二分之一位置** 为调整基准 |
| **一般形态** | 大阳之后K线震荡下行为主，没有跌破大阳线最低价 | 强度最弱，需结合其他信号 |

#### 2.3 大阳线标准

- 单根大阳线：涨幅 **> 5%** 以上或涨停板
- 连续小阳：两三根连续小阳累计涨幅 **> 7%**

#### 2.4 介入条件（五条规则）

1. **第一根大阳线幅度越大越好**，最好是5%以上的大阳线或涨停板
2. **上升放量介入**，否则按兵不动，可将成功率提高到 **80%以上**
3. **最后的上升时间不能拖过第9根K线**，如果第9根K线依旧盘整，那么在第11根K线开始引发趋势急速下跌的可能性极大
4. **市场处于弱势行情**，20日均线拐头向下时，任何类似单阳不破形态的都不要介入，尽量避开
5. **市场进入强势阶段**，20日均线拐头向上并持续延伸时，此阶段出现的单阳不破形态才能介入买进

#### 2.5 注意事项

- 如果个股持续放量上攻已经持续了2-3天，就形成了 **攻击群**，不能称之为单阳不破
- 上升时间不宜拖过第9根K线，否则下跌风险增大
- 需结合20日均线方向判断市场强弱

### 三、量能选股法

#### 3.1 放量标准

- 放量一般是 **前期量能的2-3倍**
- 如果量能出来，**第二天继续创新高**，就是个买点，可开始建仓
- 放量上涨、缩量回调继续买入，后市继续创新高

#### 3.2 放量突破买入法

- **巨量交易理论**：对于放巨量的个股，股价再次突破放量当天的最高价，就是绝好买入时机
- 股价到达前期阻力位处出现绿巨量是正常的走势，但也是短线离场的点位
- 突破放量当天最高价，说明放量当天买入的所有人都获利了
- 股价到达前期阻力位的放量行为，大概率是 **主力吸筹** 的表现
- 个股要选择小盘股，**流通盘不超过5亿** 最佳，主力才好控盘

> **核心观点**："能够解放所有套牢盘的资金，不是解放军，一定是来盈利的。"

#### 3.3 地量买入法

**地量特征：**
- 支撑位出现 **地量小阳线** 就是买点
- 首先是支撑有效，然后是地量（成交量新低，越低越好）

**地量的四种含义：**
1. **行情清淡时**：持股的不想卖，持币的不愿买，往往是中长线买家进场时机
2. **股价即将见底时**：该卖的已卖，不想卖的也不再卖，地量持续出现
3. **主力震仓洗盘末期**：主力通过地量判断震仓是否有效
4. **拉升前整理时**：确认盘子已经很轻，筹码保持良好锁定性（"锁仓"）

**判断逻辑**：地量出现→大家都不愿动→主力拉升无抛压→出现小阳线→多头占优势→明显底部

#### 3.4 阻力位滞涨理论（三天原则操作法）

**操作规则：**
1. 成交量明显放大，股价上涨到前期阻力位，出现个股滞涨特征，则极有可能回调
2. 第1天出现绿巨量
3. 第2天突破绿量最高价建仓，建仓当天出现长上影
4. 第3天如果量缩，同时价格没有突破长上影最高价，就在第3天收盘前出场

> **三天原则**：从发现巨量开始（不论红绿），只给三天时间判断

#### 3.5 回调到位的判断

- 每次突破都会出现回调
- 在前期的支撑位出现 **地量小阳线** 就是买点
- 支撑有效 + 地量出现 + 小阳线 = 二次入场机会

### 四、基本面选股法

#### 4.1 题材易逝，价值永恒

**核心原则**：科技为矛，医药为盾，趋势向导，业绩为王，高抛低吸吃大肉。

#### 4.2 行业景气度分析

**主线方向：**
- **泛疫情**：受益概念食品、医药
- **政策/国策题材**：
  - 顶层设计：数字货币
  - 新老基建：大数据、云计算等
- **经济复苏方向**：
  - 基础产业：水泥、零售、食品饮料（环境越恶劣需求越旺盛）
  - 政策驱动新基建：大数据、云计算

**一季报数据验证**：从4月1日到目前，股价涨幅最大的板块是 **半导体** 和 **食品饮料**，市场炒作逻辑是追捧利润增长较快的板块，而非单纯的热点题材。

**下一阶段炒作方向：**
1. 盈利水平持续增长的板块（如半导体、科技股）
2. 经济复苏和政策刺激的方向（后疫情时代经济缓慢恢复）

#### 4.3 业绩增长选股

**一季报筛选要点：**
- 关注 **归属上市公司股东净利润** 同比增长
- 关注 **ROE（加权净资产收益率）** 同比增长（衡量主营能力强弱的核心指标）
- 关注 **毛利率** 增长水平（衡量行业成长性的关键）
  - 毛利率 = 主营业务利润 ÷ 主营业务收入
  - 主营业务利润 = 主营业务收入 - 主营业务成本 - 主营业务税金
  - 毛利率若大幅下滑1%，行业整体利润就会大幅衰减

**筛选门槛**：选取一季报增幅榜时，将去年一季度净利润门槛设置在 **5000万以上**，避免因基数过小引起的高增长假象。

**数据来源**：巨潮资讯网（官方披露信息）

#### 4.4 热点题材 + 业绩支撑的双重逻辑

**选股思路框架：**
1. 行业景气度向上（政策驱动或消费复苏）
2. 个股业绩增长确定（一季报/中报高增长）
3. 技术面形态配合（突破/回踩确认）
4. 资金面关注（放量/缩量回调）

#### 4.5 案例一：雅克科技（光刻胶+业绩增长181%）

**基本面：**
- 一季度业绩逆势大增 **181%**，安全垫厚
- 主营电子材料（光刻机、光刻胶），行业壁垒极高
- 今年订单需求大增，业绩不受疫情影响
- 主营业务单一，未来更受资金追捧

**财务数据验证：**
- 归属上市公司股东净利润：比上年同期大涨 **181%**
- ROE：今年一季度 **2.6%**，去年一季度 **0.99%**（增长2倍有余）
- 主营业务利润大幅增加 **159%**（税金降低、财务费用降低、主营收益增加、投资收益增加）

**技术面：**
- 出现 **长阳七星** 走法
- **灵猴探路** 均线体系战法
- 带量突破季线承压，完成缩量回踩
- 也是 **出水芙蓉** 形态

#### 4.6 案例二：重庆啤酒（消费+业绩增长）

**选股逻辑：**
1. **政策催化**：疫情后提振消费政策刺激，是最有效的稳增长手段
2. **经济复苏**：全球疫情导致进出口受限，基础物质成为经济增长点
3. **防御属性**：不确定性上升，避险情绪升温，酿酒作为防御性板块受资金青睐
4. **行业地位**：啤酒概念双龙之一，业绩三年持续增长
5. **注册制利好**：注册制下资金向核心资产龙头集中

**技术面：**
- 单阳不破叠加 **长阳七星** 技术
- 平台突破形态

### 五、单阳不破 + 长阳七星综合战法

#### 5.1 战法定义

将 **单阳不破** 形态与 **长阳七星** 形态结合使用，形成双重确认的买入信号。

#### 5.2 操作要点

- 单阳不破提供底部支撑确认（大阳线后回调不破最低价）
- 长阳七星提供趋势延续信号（平台整理后的突破）
- 结合 **放量突破** 确认买入点
- 配合 **20日均线向上** 确认市场处于强势阶段

#### 5.3 实战案例：重庆啤酒

```
重庆啤酒选股逻辑框架：
├── 基本面：业绩三年持续增长，啤酒龙头
├── 技术面：单阳不破 + 长阳七星 + 平台突破
├── 题材面：消费刺激政策 + 经济复苏 + 防御属性
└── 资金面：注册制下核心资产受追捧
```

#### 5.4 注意事项

- 综合战法需 **多重信号共振** 方可使用
- 单阳不破 + 长阳七星同时出现，胜率更高
- 仍需遵守单阳不破的5条介入条件
- 做好止损止盈的风险管理

### 六、风险控制与交易纪律

#### 6.1 止损原则

- 制定交易计划，控制好资金仓位管理
- 该亏损时做好可控范围内的本金保护
- 股票形态破坏时要及时止损，避免短线变中线、中线变长线

#### 6.2 仓位管理

- 不奢求十全十美，没有谁可以百发百中
- 做股票只做大概率
- 不要有死守思维，该止损就止损

#### 6.3 注册制下的选股方向

- 注册制让股市数量扩容，资金必然在质量上下功夫
- **核心资产龙头** 将再次吸引市场目光
- 垃圾股、仙股、白菜股面临淘汰赛
- 壳公司估值缩水，资金释放到更有价值的公司
- 选股向 **行业龙头、业绩确定性高、ROE持续增长** 的标的倾斜
