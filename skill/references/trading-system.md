### 一、仓位控制

#### 核心原则

1. **轻仓保命**
   - "何以解忧唯有杜康，何以保命唯有轻仓"——最核心的仓位管理信条
   - "心态的失衡源自仓位的失衡"——仓位过大是心态崩盘的根源
   - "船小好调头"——任何时候不满仓、不重仓，保持灵活性

2. **仓位策略**
   - 3-5成仓位，进可攻退可守（"进可攻，退可守"）
   - 任何时候买股票不要满仓、重仓；满仓、重仓只适合牛市，但2008年之后牛市基本宣告结束，当前主要是熊市和猴市
   - "熊市学技术，猴市轻仓干。地里有粮，口里不慌，交易也是如此"

3. **仓位失衡的后果**
   - 炒股最扎心的不是买到下跌的股票，而是重仓套在一只股票，动也动不了，割也割不掉，打发了时间，耗费了青春
   - 满仓重仓→从主动沦为被动→彻底被套牢
   - 涨一点不够塞牙缝，跌一点浮亏加大，内心压力越来越大

4. **补仓条件**
   - 补仓没错，但如果趋势变化了，就没补仓的必要了
   - 只有在趋势健康、支撑有效时才补仓
   - 跌破重要支撑或趋势走坏时，及时止损才是王道，不应继续补仓

5. **仓位与机会**
   - 手里其他股票套住了就没有仓位干新的行情，会错失行情
   - 案例：疫情期间很多人知道要炒口罩、医药、在线教育，但重仓套在其他股上无法参与
   - 解套的本质：释放仓位和资金，用来做差价、弥补填充，而非"解套你的股票"

#### 常见错误

- 亏损5%不愿意卖 → 跌破支撑不愿意卖 → 跌到20%不想卖 → 跌到50%不能卖 → 不断加仓至满仓动不了 → 开启长达数月甚至数年的解套旅程
- "没事，股票总会涨起来的，大不了留给儿女当嫁妆"——这是市场最大的谎言，一般有这样心理的都是被套的开始

### 二、止损纪律

#### 止损的重要性

- 保护本金优先于追求利润
- 先保护本金，再来想利润
- "留得青山在不愁没柴烧，先保住本金，才有翻身的希望"
- "炒股最扎心的不是买到下跌的股票，而是重仓套在一只股票"
- 该亏损的时候就做好可控范围内的本金保护，不要觉得亏损就一定是坏事，有时候小亏也是一种赚

#### 止损设置方法

1. **支撑位下方止损**
   - 跌破重要趋势线支撑应当及时止损
   - 跌破重要均线（如MA20）应止损——"带上止损是为了主力洗盘变出货"
   - 上升趋势线被有效跌破时就是一个卖出信号

2. **重要均线（MA20）作为防御线**
   - MA60（季线）作为生命线，依托此处进攻
   - MA20（20日均线）作为短期均线的中军，作为防御（止损）位
   - 案例：雅克科技的止损带在20日均线附近

3. **趋势线跌破止损**
   - 三三原则判断有效跌破：突破时间为3天或突破幅度达3%
   - 上升趋势线一旦被有效跌破就演变为压力线

#### 交易原则

- 选股时给出选入的理由，包括买点、卖点，最重要的少不了止损价
- 一旦到了止损价，毫不犹豫地执行，不去侥幸后面会如何
- "不要心存运气、侥幸心理"——一切源自侥幸心理以及不甘于止损
- 卖有两种方式：赚钱的时候卖是收割利润，亏损的时候到达止损卖是减少损失

#### 案例：三孚股份的套牢教训

1. 3月13号尾盘追入，买入理由只是"感觉不错，可能要涨"
2. 买了2000股，跌了就补，最终补到1万股，本金不到30万
3. 题材属于化工，不是当时的热点
4. 3月16号出现典型的冲高回落流星线（长上影）——懂K线形态应该卖出
5. 连续两天放量下跌——典型的出货信号
6. 跌破重要的趋势线支撑——应及时止损
7. 若有止损意识最多亏损6%，实际亏损达30%

**教训总结**：
- 如果知道一点趋势技术，此票最多亏损6%
- 不能满仓重仓，几乎全部身家投入一只股票
- 没有止损意识，从主动沦为被动，彻底套牢
- 趋势变化了就没必要补仓，及时止损才是王道

### 三、交易心理

#### 关于止盈与止损的心态

- "不要想着买入的每只股票必须盈利才能卖"——这是大错特错
- 卖有两种方式：赚钱卖是收割利润，亏损卖是减少损失
- 这个市场没有谁可以一步登天，也没有谁买入的股票全部盈利，神仙也做不到
- 享受股票带来利润的同时也要接受它可能存在的风险
- "我们做交易，不是神仙，不可能只赚不亏，有赚有亏才是正常的交易之路"

#### 克服常见心理误区

1. **克服贪婪**
   - "贪多嚼不烂"——达到预期利润就收割，不追求极致
   - 案例：雅克科技有20%的利润就分批卖出，因为接近前期高点需要警惕双顶

2. **学会空仓和忍耐**
   - 股票买进去后首先要有的不是盈利预期，而是风险控制
   - 在猴市中更多要抽时间学习，为牛市做充足准备

3. **避免急于求成**
   - 很多人买股异常热情，但不做功课、不知买入理由
   - 仅凭感觉买入，股价波动又引发焦虑

4. **保持理性而非感觉**
   - "感觉不错、感觉要涨"不是买入理由
   - 理性交易往往能带来回报，冲动买卖只会被惩罚
   - 建立完整的交易体系：有买入依据、有买点、有止损点、有目标价

5. **核心心态**
   - "不要心存运气、侥幸心理"
   - 该亏损时就做好可控范围内的本金保护
   - "心态的失衡源自仓位的失衡"
   - "不要觉得亏损就一定是坏事，有时候小亏也是一种赚"

#### 交易中的理性思维

- 股市是行内人赚行外人的钱，这个市场有人赚就一定有人亏
- 要战胜那70%的亏损者，需要学习更多的股票知识、技术，建立起一套属于自己的交易体系
- 炒股就是行内人赚行外人的钱，真正的交易时间并非只有开盘四小时，更多的是开盘前的分析和收盘后的复盘
- "赚钱了要知道为什么赚，亏钱了也要知道为什么亏，做到心中有数，而不是凭运气"

### 四、基本面分析（F10分析法）

#### ST/*ST股票解释

- **ST**：Special Treatment，特殊处理的股票，有退市风险。连续两年净利润为负，或财务造假、资不抵债出现其他财务异常状况
- ***ST**：三年财务状况不佳，提出退市预警的股票，退市风险更大
- 类比：学生两次不及格加ST（留级），再不及格加*ST（劝退）
- 注册制推进下，壳资源大幅贬值，ST股大面积腰斩、向1元面值靠拢
- 创业板注册制让垃圾股、仙股、白菜股面临淘汰赛

#### 市盈率（PE）的用法

- PE = 回本需要的年数
- 例如硕世生物PE=21倍，即投资回本需要21年
- 做长线投资，不选PE高于50倍的标的（科创板普遍50倍以上）

#### 主营业务分析

- **主营占比**：主营业务的占比越高，说明拳头产品在市场中越突出，行业壁垒越高
- 东投一下西投一下、毛利率都不高的企业不具备长线投资基础
- 硕世生物主营业务（体外诊断试剂）占比94.65%
- 雅克科技主营电子材料（光刻胶），行业壁垒极高
- 主营业务单一且壁垒高的企业更受资金追捧

#### 毛利率分析

- **制造业**：毛利率30%以上算优秀（参考格力、美的）
- **互联网企业**：毛利率50%以上算优秀
- 硕世生物毛利率85.11%——盈利能力非常强
- 贵州茅台毛利率93%（机构资金抱团之王）
- 毛利率大幅度下滑1%，行业整体利润就会大幅度衰减
- 运输、能源、媒体、服装受疫情影响毛利率大幅下滑——运输板块下降10%，几乎赔进本金，这就是巴菲特清空航空股的原因

#### ROE加权净资产收益率

- **定义**：每年净资产回报率，衡量企业主营能力强弱的简单粗暴指标
- ROE超过5%的企业盈利能力较强
- 要看ROE的增长趋势（同比变化）而非绝对值
- 酒鬼酒和老板电器的炸雷就是因为ROE同比下降才被资金抛弃
- 案例：
  - 雅克科技：今年一季度2.6%，去年一季度0.99%，增长2倍有余
  - 华天科技：今年一季度0.81%，上年同期0.28%，翻了近3倍

#### 一季报/财报解读方法

- **巨潮资讯网**：官方披露，小道消息不可信；妖股早知道，记得读公告
- 核心指标三看：
  1. **归属上市公司股东净利润**——同比是否大幅增长
  2. **ROE**——同比是否提升
  3. **毛利率**——从利润表中计算主营利润/主营收入
- 毛利率计算公式：毛利润 = 主营业务收入 - 主营业务成本 - 主营业务税金
- 一季报中需关注主营利润增长来源（主营收益增加 vs 投资收益）

#### 基本面选股案例

**1. 硕世生物（688399）**
- PE=21倍，低于科创板平均水平
- 主营体外诊断试剂，主营占比94.65%
- 毛利率85.11%
- ROE超过5%
- 一季报业绩同比大增670%
- 做核酸检测试剂盒，全球疫情背景下需求大增
- 业绩安全垫厚，成为资金避险标的

**2. 雅克科技**
- 基本面：光刻胶龙头之一，一季报业绩同比大增181%
- 预计上半年归属母公司净利润同比大增99%-129%
- 主营电子材料，行业壁垒极高
- 技术面：长阳七星 + 灵猴探路 + 出水芙蓉形态
- 带量突破季线承压，完成缩量回踩

**3. 华天科技**
- 归属上市公司股东净利润大涨276%
- ROE：0.81%（上年同期0.28%），翻了近3倍
- 利润表：去年同期净利润1800万，今年高达7000万
- 主营业务毛利率增加非常可观

### 五、市场分析方法

#### 创业板注册制的影响分析

针对市场常见的5个疑虑，逐一解答：

**疑虑一：担心注册制分流市场资金**
- 不合逻辑的忧虑。央行不断下调利率指引，市场利率不断走低，流动性在本阶段并非主要矛盾
- 市场一面担心印钱放水过多，一面又担心流动性不足，自相矛盾

**疑虑二：担心注册制导致上市公司首发估值过高**
- 任何市场化的改革都是让市场决定哪些企业可以上市以及价格
- 如果市场认为价格过高，上市后市场将通过破发等方式调整
- 科创板上市时类似担忧存在，但投资新兴成长型公司，不应以市盈率高低判段机会——纳斯达克同样逻辑会错过亚马逊、奈飞、特斯拉

**疑虑三：担心壳公司估值缩水**
- 这正是市场改革成功的体现
- 壳公司估值缩水，将释放无效锁定的资金，重新分配到更有价值的公司
- 优质领先公司本来就是市场佼佼者，其估值本来就不含壳价值

**疑虑四：担心不具备上市资格的企业上市圈钱**
- 此担忧在任何市场都存在
- "你不可能永远欺骗所有人"——终将被揭露
- 关键在信息披露和严惩违规

**疑虑五：担心国际市场"大衰退"挑战，不是改革的最好时机**
- 任何时候都是改革最好的时候
- 不能让短期市场波动牵制长期改革步伐

**总体结论**：
- 创业板注册制让垃圾股、仙股、白菜股面临淘汰赛
- 资金必然要在质量上下功夫，核心资产龙头会再次吸引市场目光
- 注册制改革中有机会，可以把握

#### 两会行情分析

从1999年到2019年历史数据统计：

| 时间段 | 上涨概率 |
|--------|---------|
| 两会前一个月 | 81% |
| 两会前两周 | 62% |
| 两会期间 | 57% |
| 两会后两周 | 67% |
| 两会后一个月 | 71% |

**板块轮动特征**：
- 两会前一个月：建筑建材、医药生物、国防军工、商业贸易上涨概率高达90%以上
- 两会前两周：医药生物、建筑建材跑赢上证指数概率80%
- 两会期间：医药生物上涨概率依旧保持在80%，各行业最高
- 两会后两周：综合板块和有色板块跑赢大盘概率70%
- 两会后一个月：有色金属板块收益率超过上证指数概率80%

**今年两会重点关注方向**：
- 新老基建贯穿全年：建材水泥、铁路公路、5G核心科技股
- 半导体、家电、基建工程
- 需规避的雷区：
  - 与疫情负相关的板块（如估值较高的口罩概念股）
  - 与海外不确定性挂钩的石油、有色等行业

#### 板块轮动策略

- **"科技为矛，医药为盾，趋势向导，业绩为王，高抛低吸来吃肉"**
- 主线一：盈利水平持续增长的板块——半导体、科技股
  - 国产替代潮和科技崛起潮能够抹平疫情影响
  - 一旦疫情影响降低，有巨大增长空间
- 主线二：经济复苏和政策刺激方向
  - 后疫情时代经济缓慢恢复，恢复的先后顺序决定炒作方向
  - 第一个恢复的基础产业：水泥、零售、食品饮料
  - 第二个恢复的政策驱动新基建：大数据、云计算等

#### 题材炒作 vs 价值投资

- **"题材易逝，价值永恒"**
- 纯题材的个股在牛市中飞得快，但熊市或牛皮市没有业绩支撑将会被资金抛弃
- 牛皮市中只有既有题材又有业绩支撑的票才能走出突破前高的二浪行情
- 基本面好的个股近期赚钱概率超过90%（统计：一季报净利润增长较大个股4月1日至今涨幅）

**两类选股逻辑**：
1. **题材类**：纯题材炒作，短线爆发力强，但缺乏持续性
2. **价值类**：既有题材又有业绩支撑，能够吸引资金不断推升，走出中长期趋势

**案例指引**：
- 雅克科技：光刻胶题材 + 业绩逆势增长181% → 走出突破前高行情
- 华天科技：半导体题材 + 净利润增长276% → 资金持续进攻
- 重庆啤酒：消费防御属性 + 业绩三年持续增长 + 注册制下核心资产 → 平台突破
